# rec/ — video explicativo

Este directorio contiene el video asciinema de **MesaCerca · el pedido completo, del carrito al pago** y el reproductor
que se usa en la página del proyecto.

- `mesacerca.cast`: grabación original (asciicast v2).
- `mesacerca.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:49. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
