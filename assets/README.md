# Assets

Carpeta para los recursos visuales del proyecto.

## Qué va aquí

| Archivo | Formato | Uso |
|---|---|---|
| `logo-mesacerca.svg` | SVG | Logo principal |
| `logo-mesacerca-mono.svg` | SVG | Versión monocromo |
| `favicon.svg` | SVG | Navegador |
| `og-image.png` | PNG 1200×630 | Redes sociales |
| `app-icon-512.png` | PNG 512×512 | PWA/App |
| `paleta.png` | PNG | Referencia de color |
| `tipografia.png` | PNG | Especimen |
| `mockups/` | PNG/Figma | Pantallas |
| `fotos/` | JPG/WebP | Platos y locales |

## Convenciones

- Nombres en minúsculas, sin espacios.
- SVG para logos e iconos.
- WebP para fotos de producto.
- Tamaño máximo de imagen: 2 MB.
- No subir assets con derechos de terceros sin licencia.
